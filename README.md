### 排版与链接解析问题说明（重要）

多个上游仓库的 Markdown 使用**站点路由式相对路径**（Starlight / VitePress 语义），例如：

- 资源 7：`[第 1 章](<./01-architecture/第 1 章　AI 原生应用的新阶段.md>)` —— 含**中文 + 全角空格**
- 资源 3：`[第 1 周](../course/week-01-role-baseline/)` —— **目录式链接**，本地实际是 `course/week-01-role-baseline.md`
- 资源 3：`[实践篇](/cases/)` —— **站点根绝对路径**

这类链接在多数 Markdown 阅读器（VS Code 内置预览、Typora、Obsidian）中**无法跳转**。已做两件事：

1. **批量修复**：把上述链接改写为指向**真实本地文件**的相对路径并做 URL 编码（共修正 **480 余处**）
2. **生成导航页**：各资源提供 `本地导航.html` 作为稳定入口

三种可选阅读方式：**① 导航页**（零依赖，推荐）／**② VS Code `Ctrl+Shift+V`**（支持相对路径跳转）／**③ 官方站点**（需 `npm ci`，非离线）。

## 五、结合半导体 Fab 场景的阅读路径

您所在的 Fab 信息部 AI 应用组正从业务专家转向 FDE，以**备品备件管理**（需求预测、动态补库、消费监控、缺料预警）为首个落地项目。建议路径：

1. **建立角色认知**（约半天）  
   资源 2 第一部（第 1–5 章）+ 资源 4 第 1 章 + 资源 3 `what-is-fde.md`、`skills.md` —— 厘清 FDE 与售前、咨询、外包、客户成功的边界。
2. **对齐制造业打法**（约 1 天）  
   资源 1《FDE 实战蓝皮书》制造/供应链段 + 大型客户分层；资源 5 中文白皮书的**工厂实操案例** —— 您的 Fab 属于大型制造客户，打法与中小客户不同。
3. **打通工程底座**（重点）  
   资源 2 第三部（数据与权限、Agent 约束、评测、自证、成本）+ 资源 3 第 9–18 周 + 资源 7 运行/治理篇 —— 直接对应「出库数据止于 Module + Section 粒度」的现实约束。
4. **补充中国实践参照**  
   资源 7 实践篇的制造业与连锁企业案例（吉利汽车智能运维、塔斯汀万店连锁智能运维闭环）—— 可作为 Fab 场景的类比素材。
5. **作品集与面试准备**  
   资源 3 的 `templates/`（Discovery Brief、Eval Plan、Portfolio Rubric）+ `projects/enterprise-rag-mcp` Capstone 合同 —— 可改造为备品备件 AI 项目的交付文档。

> 提醒：资源 2、4 均强调「定制度必须下降、现场经验要产品化」「中国是一套不同打法」，与「不套模板、贴合真实运营约束」的要求一致。
